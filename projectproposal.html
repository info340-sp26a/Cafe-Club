Problem Description

  1. The problem we are addressing with our web application is the struggle that cafe owners or aspiring cafe owners face when trying to create and update menus for their establishment. The process of deciding on a menu can be a struggle because owners must decide what items to include or exclude, where on the menu they should go, and how feasible the menu is for staff of the cafe.
  2. There is no specialized system that exists to address this problem. Regular systems that people use for collaborative planning and menu planning, such as Word or Google Docs, can get messy and don’t have a way to visually rearrange items on menus easily.
  3. One app that exists to be used for a similar purpose is the app Meez. This app allows users to calculate costs based on the recipes they want to use for items in their menu. This is different from what we are making because we want to create something that handles only the decision of what items will be included in the menu, without complicating it with pricing and quantity options that come more in a later stage of restaurant/cafe planning.

App Description

Primary Users of this Web App

This web application will primarily be used by: cafe owners, managers, cafe staff, small business owners, culinary students, and event planners/pop-up vendors.

  • Cafe Owners & Managers - We believe these are going to be our primary users who would use our web application in order to design, update, and also finalize the menus for their own business.
  • Cafe Staff- By providing the cafe staff with this web application, we aim to help them view and help refine the cafe’s menu structure, item description, and also pricing whenever needed. This also allows them to be continuously updated on any menu updates and are able to keep them knowledgeable about the cafe’s menu.
  • Small Business Entrepreneurs - Those who are planning to open a cafe and want to start experimenting with various menu ideas
  • Culinary Students- The web can be used for students who are often practicing menu design or creating mock concepts for learning or fun purposes
  • Event Planners or Pop-up Vendors - We believe this group of people are often redesigning or creating new menus whenever they are assigned to a new event. With this app we are able to allow them to save their menus and have temporary menus for various events

Some impacts we believe it might have on minorities is that although we want to make sure the app is easy to understand, non-english speakers might have a hard time being able to navigate through the cite intuitvely. Another impact of this app is that we believe it will reduce the stress load for young entrepreneurs, especially small and minority owned businesses. We believe this may be a postive website for young entrepreneurs is because it allows for a free, and easy to use tool instead of paying someone else a hefty ammount to create one. Lastly, another benefit this app may have is that since it allows for creators of the menu's to be flexible and creative, users are able to express themselves and their identity as much as possible.

What Users Will Do With the App

We hope users all around the world are able to use our platform as a way to streamline their process and create better business efficency.

  • Users will be able to create and adjust the style of their menus
  • Allow staff/clients to give feedback on what they thought about the menu
  • Experiment with different menu layout and styles
  • Organize the menu items into different sections
  • Upload pictures of their own menu items

Key Features

  • Menu Builder in which users are able to:
    • Create a new menu
    • Add section to menu (e.g., “Drinks“Desserts”)
    • Select menu colors and fonts
    • Select menu items to add to menu sections
    • Save menu
  • Add New Item where users can upload items. Once items are uploaded, they can be selected to add to menus when creating/editing a menu. Add menu items with:
    • Name
    • Price
    • Ingredients
    • (Optional) upload a picture of the item
  • Staff Approval System This feature allows the user to share the selected menu(s) with staff they choose for approval. For each menu, the app will show which staff members have approved, viewed, or dissaproved of the menu.

Information Viewed By Users

Since this is an interactive app used to create menu's, most of the apps functionality will focus on users creating. However some information we can create to be viewed by users would be:

  • Instructions on how the app works
  • A help center with commmon problems and solutions
  • Examples of pre-generated menus they can utilize for insipiration

In terms of what information the user would see while interacting with the app, they would see a database of the menus they have saved as well as a database of the menu items they have saved.

How App Solves the Problem

Having to brainstorm menus without having a go-to place can be a hastle for busy enterpreneurs. By having an app that lets you create menus, users can play around with designs and menu items to come up with an ideal pairing. Using our app, users are able to save time by drawing inspirations from pre-generated menu templates, and also have a place to organize their menu items and ideas. Having a set place for menu's, designers are able to effeciently receieve feedback from their staff, creating a more organized business.
